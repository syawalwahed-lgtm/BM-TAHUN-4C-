# Jelajah Peribahasa Bahasa Melayu Tahun 4

Game interaktif untuk murid Tahun 4:
- Peribahasa + nota infografik
- Snake Peribahasa
- Kuiz Pantas
- Padan Makna
- 3 tahap kesukaran
- Sistem bintang
- Nama murid
- Bunyi/efek + Speech Synthesis Bahasa Melayu (ms-MY) jika disokong peranti
- Respons “Betul! Syabas!” / “Belum tepat. Cuba lagi!”
- Responsive untuk telefon, tablet dan komputer
- Boleh dimainkan secara offline

## Cara penggunaan
1. Buka `index.html`.
2. Masukkan nama murid.
3. Pilih tahap dan misi.
4. Tekan butang Bunyi untuk mengaktifkan/menyahaktifkan audio.
5. Murid boleh melihat Nota Infografik sebelum bermain.

## GitHub Pages
1. Cipta repository baharu di GitHub, contoh: `jelajah-peribahasa-tahun4`.
2. Upload `index.html` dan `README.md`.
3. Pergi ke **Settings → Pages**.
4. Pilih **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. Simpan. GitHub akan memberikan pautan seperti:
   `https://USERNAME.github.io/jelajah-peribahasa-tahun4/`

Nota: suara menggunakan `SpeechSynthesis` peranti. Suara Melayu bergantung pada sama ada telefon/tablet/pelayar mempunyai voice `ms-MY` atau voice Bahasa Melayu yang serasi.
